逻辑回归：从概率建模到交叉熵损失

逻辑回归虽然名字里有“回归”，但它最常用于二分类问题。
给定特征 (x)，它要预测的不是一个任意实数，而是样本属于正类的概率：

[
P(y=1\mid x).
]

其中 (y\in{0,1})。

1. 模型形式

先对输入做线性变换：

[
z = w^\top x + b.
]

但 (z) 可以取任意实数，不能直接当概率。
因此逻辑回归再用一个 sigmoid 函数把它压到 ((0,1))：

[
\sigma(z)=\frac{1}{1+e^{-z}}.
]

于是模型输出为

[
\hat y = \sigma(w^\top x+b).
]

这时就可以解释为

[
P(y=1\mid x)=\hat y,\qquad P(y=0\mid x)=1-\hat y.
]

2. 为什么叫“逻辑回归”

因为它本质上是在建模对数几率。

由

[
p=\sigma(w^\top x+b)
]

可得

[
\frac{p}{1-p}=e^{w^\top x+b}.
]

两边取对数：

[
\log\frac{p}{1-p}=w^\top x+b.
]

也就是说，逻辑回归假设：样本属于正类的对数几率，与特征是线性关系。

3. 概率分布假设

由于 (y) 只有 (0) 和 (1) 两种取值，所以自然可设

[
y\mid x \sim \text{Bernoulli}(\hat y).
]

伯努利分布可统一写成

[
P(y\mid x;w,b)=\hat y^{,y}(1-\hat y)^{,1-y}.
]

这是因为：

  • 当 (y=1) 时，上式变成 (\hat y)；
  • 当 (y=0) 时，上式变成 (1-\hat y)。

4. 最大似然估计

设训练集为

[
{(xi,y_i)}{i=1}^n.
]

若样本条件独立，则整体似然函数为

[
L(w,b)=\prod{i=1}^n P(y_i\mid x_i;w,b)
=\prod{i=1}^n \hat y_i^{,y_i}(1-\hat y_i)^{,1-y_i},
]

其中

[
\hat y_i=\sigma(w^\top x_i+b).
]

为了便于优化，对似然取对数：

[
\log L(w,b)=\sum_{i=1}^n
\left[
y_i\log \hat y_i + (1-y_i)\log(1-\hat y_i)
\right].
]

逻辑回归采用最大似然估计，即最大化 (\log L(w,b))。
等价地，也可以最小化负对数似然：

[
J(w,b)=-\sum_{i=1}^n
\left[
y_i\log \hat y_i + (1-y_i)\log(1-\hat y_i)
\right].
]

如果取平均形式，则为

[
J(w,b)=-\frac{1}{n}\sum_{i=1}^n
\left[
y_i\log \hat y_i + (1-y_i)\log(1-\hat y_i)
\right].
]

这就是二分类交叉熵损失。

5. 交叉熵为什么合理

对单个样本：

[
\ell_i=-\left[
y_i\log \hat y_i + (1-y_i)\log(1-\hat y_i)
\right].
]

分两种情况看：

当 (y_i=1)

[
\ell_i=-\log \hat y_i.
]

预测的正类概率 (\hat y_i) 越大，损失越小。

当 (y_i=0)

[
\ell_i=-\log(1-\hat y_i).
]

如果模型把负类样本预测成很大的正类概率，损失就会很大。

所以交叉熵的含义就是：
鼓励模型给正确类别更高概率，惩罚“很自信但预测错”的情况。

6. 梯度形式

记

[
z_i=w^\top x_i+b,\qquad \hat y_i=\sigma(z_i).
]

则单样本损失对 (z_i) 的导数为

[
\frac{\partial \ell_i}{\partial z_i}=\hat y_i-y_i.
]

进一步得到

[
\nabla_w \ell_i = (\hat y_i-y_i)x_i,
\qquad
\frac{\partial \ell_i}{\partial b}=\hat y_i-y_i.
]

这说明参数更新的核心就是：

[
\text{预测值} - \text{真实值}.
]

7. 分类边界

虽然逻辑回归输出的是非线性的 sigmoid 概率，但分类边界仍然是线性的。

通常以 (0.5) 为阈值分类：

[
\hat y \ge 0.5 \Rightarrow 1,\qquad \hat y < 0.5 \Rightarrow 0.
]

而

[
\sigma(z)=0.5 \iff z=0,
]

所以分界面满足

[
w^\top x+b=0.
]

因此逻辑回归本质上仍然是一个线性分类器。

8. 与朴素贝叶斯、SVM的区别

与朴素贝叶斯相比

  • 朴素贝叶斯是生成式模型，建模的是 (P(x\mid y)) 和 (P(y))；
  • 逻辑回归是判别式模型，直接建模 (P(y\mid x))。

与 SVM 相比

  • 逻辑回归重在输出概率；
  • SVM 重在寻找最大间隔分类面。

因此，逻辑回归特别适合需要概率解释的场景。

9. 总结

逻辑回归的整条主线可以概括为：

[
z=w^\top x+b
]

[
\hat y=\sigma(z)=\frac{1}{1+e^{-z}}
]

[
y\mid x\sim \text{Bernoulli}(\hat y)
]

[
L(w,b)=\prod_{i=1}^n \hat y_i^{y_i}(1-\hat y_i)^{1-y_i}
]

[
\log L(w,b)=\sum_{i=1}^n\left[y_i\log \hat y_i+(1-y_i)\log(1-\hat y_i)\right]
]

[
J(w,b)=-\log L(w,b)
]

[
\Rightarrow
J(w,b)=
-\sum_{i=1}^n
\left[
y_i\log \hat y_i+(1-y_i)\log(1-\hat y_i)
\right].
]

所以，逻辑回归的交叉熵损失并不是凭空定义出来的，而是由伯努利分布假设 + 最大似然估计自然推导得到的。

PCA详细推导

Posted on 2026-04-21 Edited on 2026-04-28 In ML

note: 路线二三比较简单

1. 问题设定

设样本为
[
x1,\dots,x_n\in\mathbb{R}^d,
]
先假设它们已经中心化：
[
\frac{1}{n}\sum{i=1}^n x_i = 0.
]

把它们按列拼成数据矩阵
[
X=[x_1,\dots,x_n]\in\mathbb{R}^{d\times n}.
]

PCA 要做的是：找一个 (k) 维子空间，把每个 (x_i) 投影进去，再从这个子空间重构回来，使总重构误差最小。

2. 用矩阵 (U) 表示 (k) 维子空间

设
[
U=[u_1,\dots,u_k]\in\mathbb{R}^{d\times k},
]
其中 (u_1,\dots,u_k) 是这个 (k) 维子空间的一组标准正交基。

于是有约束
[
U^\top U = I_k.
]

2.1 (I_k) 的含义

(I_k) 表示 (k\times k) 的单位矩阵：
[
I_k=
\begin{bmatrix}
1&0&\cdots&0\
0&1&\cdots&0\
\vdots&\vdots&\ddots&\vdots\
0&0&\cdots&1
\end{bmatrix}.
]

它的性质是
[
I_k^\top = I_k,
\qquad
I_k^{-1}=I_k,
\qquad
AI_k=A,
\qquad
I_kB=B,
]
只要乘法维度匹配。

2.2 (U^\top U = I_k) 表示什么

因为
[
(U^\top U)_{ij}=u_i^\top u_j,
]
所以
[
U^\top U = I_k
]
等价于

  • (u_i^\top u_i=1)：每列长度为 1；
  • (u_i^\top u_j=0)（当 (i\neq j) 时）：不同列两两正交。

也就是说，(U) 的列向量是一组标准正交基。

注意一般 (U) 不是方阵，所以通常
[
UU^\top \neq I_d.
]

3. 投影与重构怎么写

对于任意样本 (x\in\mathbb{R}^d)，它在子空间基 (U) 下的低维坐标是
[
z = U^\top x \in \mathbb{R}^k.
]

再从低维坐标重构回原空间：
[
\hat x = Uz = UU^\top x.
]

所以 (UU^\top) 是“投影到该 (k) 维子空间”的矩阵。

3.1 为什么 (UU^\top) 是投影矩阵

要看两个性质。

对称性

[
(UU^\top)^\top = UU^\top.
]

幂等性

[
(UU^\top)^2 = UU^\top UU^\top = U(U^\top U)U^\top = UI_kU^\top = UU^\top.
]

一个矩阵如果既对称又幂等，它就是一个正交投影矩阵。

所以
[
\hat x=UU^\top x
]
确实是 (x) 在该子空间上的正交投影。

4. PCA 的最小化重构误差目标

对每个样本，重构误差为
[
|x_i-\hat x_i|^2=|x_i-UU^\top x_i|^2.
]

总重构误差为
[
J(U)=\sum_{i=1}^n |x_i-UU^\top x_i|^2,
]
约束是
[
U^\top U=I_k.
]

写成矩阵形式：
[
J(U)=|X-UU^\top X|_F^2.
]

这里 (|\cdot|_F) 是 Frobenius 范数。

5. 预备公式：这些衔接处后面都会用到

5.1 Frobenius 范数与迹

对任意矩阵 (A=(a{ij}))，定义
[
|A|_F^2 = \sum{i,j} a_{ij}^2.
]

另一方面，
[
\operatorname{tr}(A^\top A)
]
等于 (A^\top A) 对角线元素之和。

而
[
(A^\top A){jj}=\sum_i a{ij}^2,
]
所以
[
\operatorname{tr}(A^\top A)=\sumj\sum_i a{ij}^2=\sum{i,j}a{ij}^2=|A|_F^2.
]

因此
[
|A|_F^2=\operatorname{tr}(A^\top A).
]

5.2 迹的线性性与循环性质

迹满足线性性：
[
\operatorname{tr}(A+B)=\operatorname{tr}(A)+\operatorname{tr}(B),
\qquad
\operatorname{tr}(cA)=c\,\operatorname{tr}(A).
]

还满足循环不变性：
[
\operatorname{tr}(ABC)=\operatorname{tr}(BCA)=\operatorname{tr}(CAB),
]
只要乘法维度匹配。

这个性质非常重要，因为它允许我们把 (dU) 调到最后，便于识别梯度。

5.3 为什么

[
d\,\operatorname{tr}(Y)=\operatorname{tr}(dY)
]

因为
[
\operatorname{tr}(Y)=\sumi Y{ii},
]
对它取微分，
[
d\,\operatorname{tr}(Y)=d\left(\sumi Y{ii}\right)=\sumi d(Y{ii}).
]

而
[
\operatorname{tr}(dY)=\sumi (dY){ii}=\sumi d(Y{ii}).
]

所以
[
d\,\operatorname{tr}(Y)=\operatorname{tr}(dY).
]

5.4 乘积的微分法则

和普通微分一样：
[
d(AB)=dA\cdot B+A\cdot dB.
]

如果有三项：
[
d(ABC)=dA\cdot BC+A\cdot dB\cdot C+AB\cdot dC.
]

因此
[
d(U^\top S U)=dU^\top S U+U^\top dS\,U+U^\top S\,dU.
]

在 PCA 里 (S) 是常量矩阵，所以 (dS=0)，于是
[
d(U^\top S U)=dU^\top S U+U^\top S\,dU.
]

5.5 一个常用变形：把 (dU^\top) 变成 (dU)

后面常用到
[
\operatorname{tr}(M\,dU^\top)=\operatorname{tr}(M^\top dU).
]

原因很简单，因为
[
\operatorname{tr}(M\,dU^\top)=\operatorname{tr}\big((M\,dU^\top)^\top\big)=\operatorname{tr}(dU\,M^\top).
]
再用循环性质，
[
\operatorname{tr}(dU\,M^\top)=\operatorname{tr}(M^\top dU).
]

所以以后见到 (dU^\top)，都可以改写成 (dU) 的形式。

6. 把目标函数改写成迹形式

从
[
J(U)=|X-UU^\top X|_F^2
]
开始。

利用
[
|A|_F^2=\operatorname{tr}(A^\top A),
]
得
[
J(U)=\operatorname{tr}\Big((X-UU^\top X)^\top (X-UU^\top X)\Big).
]

先看转置：
[
(X-UU^\top X)^\top = X^\top - X^\top UU^\top.
]

代入：
[
J(U)=\operatorname{tr}\Big((X^\top-X^\top UU^\top)(X-UU^\top X)\Big).
]

展开乘法：
[
J(U)=\operatorname{tr}(X^\top X)
-\operatorname{tr}(X^\top UU^\top X)
-\operatorname{tr}(X^\top UU^\top X)
+\operatorname{tr}(X^\top UU^\top UU^\top X).
]

由于
[
UU^\top UU^\top = U(U^\top U)U^\top = UI_kU^\top = UU^\top,
]
最后一项化成
[
\operatorname{tr}(X^\top UU^\top X).
]

所以
[
J(U)=\operatorname{tr}(X^\top X)-\operatorname{tr}(X^\top UU^\top X).
]

再用迹的循环性质：
[
\operatorname{tr}(X^\top UU^\top X)=\operatorname{tr}(U^\top XX^\top U).
]

因此
[
J(U)=\operatorname{tr}(X^\top X)-\operatorname{tr}(U^\top XX^\top U).
]

因为 (\operatorname{tr}(X^\top X)) 与 (U) 无关，是常数，所以最小化 (J(U)) 等价于最大化
[
\operatorname{tr}(U^\top XX^\top U).
]

若定义协方差矩阵
[
S=\frac{1}{n} XX^\top,
]
由于 (\frac{1}{n}) 只是常数因子，不影响最优 (U)，于是等价问题写成
[
\max_{U^\top U=I_k}\operatorname{tr}(U^\top S U).
]

7. 用矩阵拉格朗日乘子法处理约束

现在我们要求解
[
\max_{U^\top U=I_k}\operatorname{tr}(U^\top S U).
]

7.1 为什么约束需要“矩阵乘子”

约束
[
U^\top U-I_k=0
]
不是一个标量约束，而是一个 (k\times k) 的矩阵约束。

它实际上包含了 (k^2) 个标量约束：
[
(U^\top U-Ik){ab}=0,
\qquad
a,b=1,\dots,k.
]

如果按普通拉格朗日乘子写，应该是
[
\mathcal L=f(U)-\sum{a,b}\lambda{ab}(U^\top U-Ik){ab}.
]

把这些 (\lambda{ab}) 组成矩阵 (\Lambda=(\lambda{ab}))，就可以紧凑写成
[
\mathcal L=f(U)-\operatorname{tr}\big(\Lambda^\top (U^\top U-I_k)\big).
]

这就是矩阵形式的拉格朗日乘子法。

通常直接写成
[
\mathcal L(U,\Lambda)=\operatorname{tr}(U^\top S U)-\operatorname{tr}\big(\Lambda(U^\top U-I_k)\big).
]

7.2 为什么可设 (\Lambda) 为对称矩阵

因为
[
U^\top U-I_k
]
本身就是对称矩阵。

把任意 (\Lambda) 分解成
[
\Lambda=\Lambda_s+\Lambda_a,
]
其中 (\Lambda_s) 对称，(\Lambda_a) 反对称。

则
[
\operatorname{tr}\big(\Lambda(U^\top U-I_k)\big)=
\operatorname{tr}\big(\Lambda_s(U^\top U-I_k)\big)
+
\operatorname{tr}\big(\Lambda_a(U^\top U-I_k)\big).
]

而反对称矩阵乘对称矩阵的迹为 0，所以只有对称部分起作用。故可不失一般性地设
[
\Lambda^\top=\Lambda.
]

8. 对拉格朗日函数求微分

构造
[
\mathcal L(U,\Lambda)=
\operatorname{tr}(U^\top S U)-
\operatorname{tr}\big(\Lambda(U^\top U-I_k)\big).
]

其中 (I_k) 是常量，所以
[
d\,\operatorname{tr}(\Lambda I_k)=0.
]

因此只需对
[
\operatorname{tr}(U^\top S U)-\operatorname{tr}(\Lambda U^\top U)
]
求微分。

8.1 第一项的微分

令
[
f(U)=\operatorname{tr}(U^\top S U).
]

则
[
df=d\,\operatorname{tr}(U^\top S U)=\operatorname{tr}\big(d(U^\top S U)\big).
]

由于 (S) 是常量矩阵，
[
d(U^\top S U)=dU^\top S U+U^\top S\,dU.
]

于是
[
df=\operatorname{tr}(dU^\top S U)+\operatorname{tr}(U^\top S\,dU).
]

现在把这两项都改成 (\operatorname{tr}(\cdots dU)) 形式。

第一项：
[
\operatorname{tr}(dU^\top S U)=\operatorname{tr}\big((SU)^\top dU\big).
]

第二项：
[
\operatorname{tr}(U^\top S\,dU)=\operatorname{tr}\big((S^\top U)^\top dU\big).
]

所以
[
df=\operatorname{tr}\Big((SU+S^\top U)^\top dU\Big).
]

因此
[
\frac{\partial}{\partial U}\operatorname{tr}(U^\top S U)=SU+S^\top U.
]

而协方差矩阵 (S) 是对称的，即
[
S^\top=S,
]
所以
[
\frac{\partial}{\partial U}\operatorname{tr}(U^\top S U)=2SU.
]

8.2 第二项的微分

令
[
g(U)=\operatorname{tr}(\Lambda U^\top U).
]

则
[
dg=\operatorname{tr}\big(\Lambda\,d(U^\top U)\big).
]

而
[
d(U^\top U)=dU^\top U+U^\top dU.
]

所以
[
dg=\operatorname{tr}(\Lambda dU^\top U)+\operatorname{tr}(\Lambda U^\top dU).
]

分别改写。

第一项：
[
\operatorname{tr}(\Lambda dU^\top U)=
\operatorname{tr}(U\Lambda dU^\top)=
\operatorname{tr}\big((U\Lambda)^\top dU\big).
]

第二项：
[
\operatorname{tr}(\Lambda U^\top dU)=\operatorname{tr}\big((U\Lambda^\top)^\top dU\big).
]

故
[
dg=\operatorname{tr}\Big((U\Lambda+U\Lambda^\top)^\top dU\Big).
]

于是
[
\frac{\partial}{\partial U}\operatorname{tr}(\Lambda U^\top U)=U\Lambda+U\Lambda^\top.
]

因为可设 (\Lambda) 对称，所以
[
\frac{\partial}{\partial U}\operatorname{tr}(\Lambda U^\top U)=2U\Lambda.
]

8.3 拉格朗日函数的一阶条件

因此
[
\frac{\partial \mathcal L}{\partial U}=2SU-2U\Lambda.
]

驻点条件为
[
2SU-2U\Lambda=0,
]
即
[
SU=U\Lambda.
]

这就是关键方程。

9. 为什么这说明 (U) 的列向量是 (S) 的特征向量

方程
[
SU=U\Lambda
]
说明 (S) 作用在 (U) 的列空间上，结果仍落在这个列空间里；也就是说这个子空间对 (S) 是不变的。

再左乘 (U^\top)，得
[
U^\top S U = U^\top U\,\Lambda = I_k\Lambda=\Lambda.
]

因此 (\Lambda) 本身是对称矩阵。

对称矩阵 (\Lambda) 可以正交对角化：存在正交矩阵 (R)，使得
[
\Lambda=RDR^\top,
]
其中 (D) 为对角矩阵。

令
[
\widetilde U = UR.
]

则
[
\widetilde U^\top \widetilde U = R^\top U^\top U R = R^\top I_k R = I_k,
]
说明 (\widetilde U) 仍满足约束。

并且
[
S\widetilde U = SUR = U\Lambda R = URD = \widetilde U D.
]

这说明 (\widetilde U) 的每一列都是 (S) 的特征向量。

所以我们总可以把最优解 (U) 选成由 (S) 的 (k) 个标准正交特征向量组成。

10. 为什么要选最大的 (k) 个特征值

设 (S) 的特征分解为
[
S=Q\operatorname{diag}(\lambda_1,\dots,\lambda_d)Q^\top,
\qquad
\lambda_1\ge\lambda_2\ge\cdots\ge\lambda_d\ge0.
]

令
[
B=Q^\top U.
]

因为 (Q) 正交且 (U^\top U=I_k)，有
[
B^\top B = U^\top QQ^\top U = U^\top U = I_k.
]

目标函数变成
[
\operatorname{tr}(U^\top S U)=
\operatorname{tr}\big(B^\top \operatorname{diag}(\lambda_1,\dots,\lambda_d) B\big).
]

把它展开：
[
\operatorname{tr}(U^\top S U)=
\sum{i=1}^d \lambda_i \alpha_i,
]
其中
[
\alpha_i=\sum{j=1}^k b_{ij}^2.
]

这些 (\alphai) 满足
[
0\le \alpha_i\le 1,
\qquad
\sum{i=1}^d \alpha_i = k.
]

所以这是一个“把总权重 (k) 分配给各个特征值”的加权和。要使它最大，显然应把权重尽可能分配给最大的那些 (\lambda_i)。最大值就是
[
\lambda_1+\cdots+\lambda_k,
]
当且仅当 (U) 取为前 (k) 个最大特征值对应的特征向量时达到。

于是最优基矩阵为
[
U_k=[u_1,\dots,u_k],
]
其中
[
Su_i=\lambda_i u_i,
\qquad
i=1,\dots,k,
]
且
[
\lambda_1\ge\cdots\ge\lambda_k.
]

11. 由最小重构误差得到的 PCA 投影矩阵公式

这里“投影矩阵”常有两种说法。

11.1 从原空间映射到低维空间的降维矩阵

低维表示为
[
z = U_k^\top x.
]

因此常说 PCA 的投影方向矩阵是
[
W=U_k.
]

如果写成变换矩阵作用在左边，也常写成
[
z=W^\top x.
]

11.2 在原空间中的正交投影矩阵

把 (x) 投影到主子空间后得到
[
\hat x = U_kU_k^\top x.
]

因此正交投影矩阵是
[
P=U_kU_k^\top.
]

12. 路线二： 最大方差准则推导 PCA

上面是从最小重构误差出发。下面给出另一条同样经典的路线：最大方差准则。

12.1 一维情形：第一主成分

设单位方向向量为
[
w\in\mathbb{R}^d,
\qquad
w^\top w=1.
]

样本 (x_i) 在方向 (w) 上的投影为
[
y_i=w^\top x_i.
]

因为数据已经中心化，所以投影后的均值也是 0：
[
\frac{1}{n}\sum{i=1}^n y_i=
\frac{1}{n}\sum{i=1}^n w^\top xi=
w^\top\left(\frac{1}{n}\sum{i=1}^n x_i\right)=0.
]

因此投影后的方差为
[
\operatorname{Var}(y)=
\frac{1}{n}\sum_{i=1}^n y_i^2.
]

代入 (yi=w^\top x_i)：
[
\operatorname{Var}(y)=
\frac{1}{n}\sum{i=1}^n (w^\top x_i)^2.
]

又因为
[
(w^\top x_i)^2=w^\top x_i x_i^\top w,
]

所以
[
\operatorname{Var}(y)=
w^\top\left(\frac{1}{n}\sum_{i=1}^n x_i x_i^\top\right)w=
w^\top S w.
]

于是第一主成分方向满足
[
\max_{w^\top w=1} w^\top S w.
]

构造拉格朗日函数
[
\mathcal L(w,\lambda)=w^\top S w-\lambda(w^\top w-1).
]

对 (w) 求导。因为 (S) 对称，
[
\frac{\partial}{\partial w}(w^\top S w)=2Sw,
\qquad
\frac{\partial}{\partial w}(w^\top w)=2w.
]

于是驻点满足
[
2Sw-2\lambda w=0,
]
即
[
Sw=\lambda w.
]

所以最优方向 (w) 必须是协方差矩阵 (S) 的特征向量。

若 (w) 是单位特征向量，对应特征值为 (\lambda)，则
[
w^\top S w = w^\top(\lambda w)=\lambda w^\top w=\lambda.
]

因此要使方差最大，就应选取最大特征值对应的特征向量作为第一主成分。

12.2 多维情形：前 (k) 个主成分

把前 (k) 个方向拼成矩阵
[
U=[u_1,\dots,u_k]\in\mathbb{R}^{d\times k},
\qquad
U^\top U=I_k.
]

样本投影后的低维坐标为
[
z_i=U^\top x_i.
]

投影后总方差为各坐标方差之和：
[
\sum_{j=1}^k u_j^\top S u_j=
\operatorname{tr}(U^\top S U).
]

因此最大方差准则对应的优化问题为
[
\max_{U^\top U=I_k}\operatorname{tr}(U^\top S U).
]

这和第 6 节从最小重构误差推出来的优化问题完全一致，所以得到的解也完全一致：
[
U_k=[u_1,\dots,u_k],
]
其中 (u_1,\dots,u_k) 是 (S) 的前 (k) 个最大特征值对应的标准正交特征向量。

因此从最大方差角度看，PCA 的降维公式仍然是
[
z=U_k^\top x.
]

13. 路线三：SVD 视角推导 PCA

再给出第三条经典路线：从 SVD 和最佳低秩近似出发。

13.1 数据矩阵的 SVD

对中心化后的数据矩阵
[
X\in\mathbb{R}^{d\times n}
]
做奇异值分解：
[
X=U\Sigma V^\top.
]

其中

  • (U) 的列向量是左奇异向量；
  • (V) 的列向量是右奇异向量；
  • (\Sigma) 的对角元是奇异值，满足
    [
    \sigma_1\ge\sigma_2\ge\cdots\ge\sigma_r>0,
    ]
    其中 (r=\operatorname{rank}(X))。

也可以写成分解和的形式：
[
X=\sum_{i=1}^r \sigma_i u_i v_i^\top.
]

13.2 最佳秩 (k) 近似

数值线性代数中的 Eckart—Young 定理告诉我们：在 Frobenius 范数意义下，(X) 的最佳秩 (k) 近似就是截断 SVD：
[
Xk=\sum{i=1}^k \sigma_i u_i v_i^\top
=U_k\Sigma_k V_k^\top.
]

并且
[
\min{\operatorname{rank}(\hat X)\le k}|X-\hat X|_F^2=
|X-X_k|_F^2=
\sum{i=k+1}^r \sigma_i^2.
]

所以，如果从“用一个秩不超过 (k) 的矩阵尽量逼近原数据矩阵”出发，那么最优子空间就是前 (k) 个左奇异向量张成的子空间。

13.3 为什么这和 PCA 是同一个子空间

PCA 的重构形式是
[
\hat X = U_kU_k^\top X.
]

另一方面，如果
[
X=U\Sigma V^\top,
]
并把 (U) 按前 (k) 列和其余列分块，则有
[
U=[Uk,\,U\perp].
]

于是
[
U_kU_k^\top X=
U_kU_k^\top U\Sigma V^\top=
U_k\Sigma_k V_k^\top=
X_k.
]

也就是说，PCA 的投影重构矩阵，恰好等于截断 SVD 得到的最佳秩 (k) 近似矩阵。

因此 PCA 的主子空间就是前 (k) 个左奇异向量张成的子空间。

13.4 左奇异向量为什么等于协方差矩阵的特征向量

由
[
X=U\Sigma V^\top
]
可得
[
XX^\top=
(U\Sigma V^\top)(V\Sigma^\top U^\top)=
U\Sigma\Sigma^\top U^\top.
]

由于 (\Sigma\Sigma^\top) 是对角矩阵，其对角元为 (\sigma_i^2)，所以
[
XX^\top u_i = \sigma_i^2 u_i.
]

这说明 (u_i) 是 (XX^\top) 的特征向量，对应特征值为 (\sigma_i^2)。

而协方差矩阵为
[
S=\frac{1}{n}XX^\top,
]
所以
[
Su_i=\frac{\sigma_i^2}{n}u_i.
]

因此前 (k) 个左奇异向量，正好就是协方差矩阵前 (k) 个最大特征值对应的特征向量。

13.5 从 SVD 直接读出降维坐标

PCA 的低维表示矩阵为
[
Z=U_k^\top X.
]

代入 SVD：
[
Z=U_k^\top(U\Sigma V^\top)=\Sigma_k V_k^\top.
]

因此，PCA 的低维坐标既可以写成
[
Z=U_k^\top X,
]
也可以直接写成
[
Z=\Sigma_k V_k^\top.
]

14. 三条推导路线之间的关系

现在可以把三条路线统一起来：

  1. 最小重构误差准则：
    [
    \min_{U^\top U=I_k}|X-UU^\top X|_F^2;
    ]

  2. 最大方差准则：
    [
    \max_{U^\top U=I_k}\operatorname{tr}(U^\top S U);
    ]

  3. SVD / 最佳低秩近似：
    [
    \min_{\operatorname{rank}(\hat X)\le k}|X-\hat X|_F^2.
    ]

其中第 1 条与第 2 条等价，因为
[
|X-UU^\top X|_F^2=
\operatorname{tr}(X^\top X)-\operatorname{tr}(U^\top XX^\top U),
]
第一项是常数。

第 3 条与前两条等价，因为最佳秩 (k) 近似正是
[
X_k=U_k\Sigma_kV_k^\top=U_kU_k^\top X.
]

所以三条路线最终都得到同一个结论：
[
U_k=[u_1,\dots,u_k],
]
其中 (u_1,\dots,u_k) 是协方差矩阵 (S) 的前 (k) 个最大特征值对应的标准正交特征向量。

15. 最终结论

PCA 的主子空间由协方差矩阵
[
S=\frac{1}{n}XX^\top
]
的前 (k) 个最大特征值对应的特征向量张成。

记这些特征向量组成的矩阵为
[
U_k=[u_1,\dots,u_k].
]

则

  • 降维映射为
    [
    z=U_k^\top x;
    ]

  • 原空间中的投影矩阵为
    [
    P=U_kU_k^\top;
    ]

  • 全体样本的低维表示矩阵为
    [
    Z=U_k^\top X=\Sigma_kV_k^\top;
    ]

  • 对应的重构矩阵为
    [
    \hat X=U_kU_k^\top X=U_k\Sigma_kV_k^\top.
    ]

这就是 PCA 从最小重构误差、最大方差和 SVD 三条路线得到的统一结果。

precision

在算法竞赛中，输出精度（尤其是浮点数）往往是决定 Accepted 还是 Wrong Answer 的关键细节。C++ 和 Python 在处理逻辑上有很大差异，这里为你梳理了核心用法和避坑指南。

一、 C++ 精度处理

在 C++ 中，<iomanip> 头文件是你的好伙伴。

1. 核心控制语句

  • 固定小数位数：cout << fixed << setprecision(n) << val;
    这是竞赛中最常用的方式，确保小数点后正好有 $n$ 位。
  • 有效数字：cout << setprecision(n) << val;（不加 fixed）
    控制总的有效数字位数，通常用于科学计数法要求。
  • printf 风格：printf("%.nf", val);
    简单直接，在处理大规模数据输出时性能优于 cout。

2. 常见坑点

  • 四舍五入的玄学：printf 和 setprecision 在处理“刚好在 0.5”的情况时，并不总是稳定的“四舍五入”，有时会受编译器和浮点数底层表示（IEEE 754）的影响（即“舍入到最接近的偶数”）。
    • 对策：如果对舍入要求极其严格，建议手动加上一个极小值 eps（如 $10^{-9}$），即 printf("%.2f", val + 1e-9);。
  • 输出 -0.00：当计算结果是一个极小的负数（如 -0.0000001）且保留两位小数输出时，可能会得到 -0.00。
    • 对策：在输出前进行判断：if (abs(val) < eps) val = 0;。

二、 Python 精度处理

Python 的 float 默认就是双精度（相当于 C++ 的 double），语法更简洁。

1. 核心控制语句

  • f-string (推荐)：print(f"{val:.nf}")
  • format 函数：print("{:.nf}".format(val))
  • % 运算符：print("%.nf" % val)

2. 常见坑点

  • round() 函数的背叛：Python 的 round(x, n) 采用的是 “四舍六入五成双”（Round half to even）。

    例如：round(2.5) 得到 2，round(3.5) 得到 4。这在很多竞赛题目要求严格四舍五入时会白给。

    • 对策：使用 Decimal 模块或手动处理：int(val * 10**n + 0.5) / 10**n。
  • 浮点数运算误差：Python 虽然动态类型很爽，但浮点数依然存在 $0.1 + 0.2 \neq 0.3$ 的问题。

算法竞赛中的“避坑”与选择建议

1. 什么时候选树状数组？

  • 追求速度：当题目时限非常紧（如 $10^6$ 数据量），树状数组的常数优势巨大。
  • 求逆序对：这是树状数组最经典的用法。
  • 维度增加：在处理二维或三维空间问题时，树状数组的实现远比多维线段树简单。

2. 什么时候选线段树？

  • 区间修改 + 区间查询：这是线段树的统治区，通过 Lazy Tag（懒标记）可以高效处理。
  • 非可减性维护：比如维护区间的最大值（RMQ），由于最大值不满足可减性，树状数组处理起来很麻烦，而线段树游刃有余。
  • 复杂信息合并：如维护区间最长连续上升子序列，线段树的节点合并逻辑非常清晰。

3. 什么时候选分块？

  • “强制在线”且逻辑复杂：有些操作线段树难以通过标记下传实现（如区间内大于 $x$ 的数有多少个），此时分块配合块内排序或桶可以解决。
  • 时间换空间：如果内存限制极其严格（如 64MB），线段树的 4 倍空间可能炸内存，分块更节省。
  • 作为保底方案：在考场上如果想不出线段树的标记合并逻辑，写一个 $O(n\sqrt{n})$ 的分块通常能拿到 70%~100% 的分数。

总结建议

  • 入门阶段：先练熟树状数组，再死磕线段树。
  • 实战策略：能用树状数组不用线段树（快且好写）；能用线段树不用分块（稳且不被卡常）；如果题目要求太奇葩，果断上分块或莫队。

Tarjan

Tarjan 算法的核心在于通过一次 DFS 利用栈和两个关键数组 $dfn$ 和 $low$ 来挖掘图的结构特征。

1. 核心定义：$dfn$ 与 $low$

这是 Tarjan 算法的灵魂，理解了这两个数组，算法就理解了一半：

  • $dfn[u]$：时间戳。节点 $u$ 在 DFS 过程中被访问的先后顺序（从 1 开始递增）。
  • $low[u]$：追溯值。节点 $u$ 通过树枝边或特定的反向边能够回溯到的 $dfn$ 最小的节点编号。
    • 它代表了节点 $u$ 所在的连通结构的“最高点”。

2. 三个 Tarjan 算法对比总结

A. 有向图：强连通分量 (SCC)

  • 目的：找极大的子图，使得其中任意两点可互相到达。
  • $low$ 更新时机：
    1. 遇到未访问节点 $v$：递归后，$low[u] = \min(low[u], low[v])$。
    2. 遇到已访问且在栈中的节点 $v$：$low[u] = \min(low[u], dfn[v])$。
  • 判断时机：
    • 当 DFS 回溯时，如果 $dfn[u] == low[u]$，说明 $u$ 是该 SCC 的“根”。此时将栈中 $u$ 及其上方的节点全部弹出，这些节点构成一个 SCC。

B. 无向图：割点与点双连通分量 (v-BCC)

  • 目的：找删去后会使原图不连通的点。
  • $low$ 更新时机：
    1. 遇到未访问节点 $v$：递归后，$low[u] = \min(low[u], low[v])$。
    2. 遇到已访问且不是父节点的节点 $v$：$low[u] = \min(low[u], dfn[v])$。
  • 判断条件：
    • 非根节点 $u$：存在一个子节点 $v$，使得 $low[v] \ge dfn[u]$（说明 $v$ 无法绕过 $u$ 回到更高处）。
    • 根节点 $u$：在 DFS 树上有两个或更多独立的子树。

C. 无向图：割边（桥）与边双连通分量 (e-BCC)

  • 目的：找删去后会使原图不连通的边。
  • $low$ 更新时机：与割点基本一致，但必须严格限制不通过当前输入的这条边回到父节点（处理重边时需记录边编号）。
  • 判断条件：
    • 对于边 $(u, v)$，如果 $low[v] > dfn[u]$，则该边为桥（说明从 $v$ 出发无论如何也回不到 $u$ 或 $u$ 以上的点）。

3. 实现中的关键细节

细节 有向图 (SCC) 无向图 (割点/桥)
栈的作用 记录当前可能属于同一个 SCC 的节点。 割点通常不强制用栈，点双/边双才需要栈存边或点。
父节点回溯 不需要考虑父节点。 必须跳过父节点（或进来的那条边），否则 $low$ 永远等于 $dfn$。
更新逻辑 只有在栈中的点才能更新 $low$。 只要不是父节点就能更新 $low$（表示存在反向边）。
判等逻辑 $dfn == low$ 是判定 SCC 结束的标志。 $low[v] \ge dfn[u]$ 是判定 $u$ 是割点的标志。

🛠️ 避坑指南：

  1. 重边问题：在求无向图桥时，不能简单判断 v != fa，而要记录进入 $u$ 的边 ID，防止通过重边直接回到父节点导致 $low$ 更新错误。
  2. 根节点特判：求割点时，DFS 的起点（根）不能用 $low[v] \ge dfn[u]$ 判断，必须看它是否有两个以上的子树。
  3. 多连通图：如果图不连通，需要对每个未访问的点跑一遍 Tarjan。

2. 直觉解释

你可以把 AdamW 想象成一个带刹车的智能小球：

  • $m_t$ (一阶矩)：就像惯性。球不会因为路面一个小坑就立刻停下，而是会根据之前的速度继续滑动，这有助于跳出局部最优。
  • $v_t$ (二阶矩)：就像路面的粗糙度自适应。如果某个方向坡度一直很大（梯度大），它会增加“摩擦力”让更新变稳；如果坡度很小，它会放大更新，确保能走得动。
  • Weight Decay ($\lambda$)：就像向心力。它不断地把参数往原点（0）拉，防止某些参数数值爆炸，从而起到正则化、减少过拟合的作用。

1. 你的直觉对了一半：Adam 的“逐元素独立性”

实际上，Adam 比你想象的更“分裂”。它并没有把所有参数视为一个整体空间中的大向量，而是把每一个标量参数（每一个权重数字）都视为一个独立的维度。

  • Adam 的视角：如果你的模型有 10 亿个参数，Adam 就像是在一个 10 亿维 的空间里。它给每一个维度（每一颗螺丝钉）都装了一个独立的自适应减震器（即 $v_t$ 项，二阶动量）。
  • 这种做法的问题：它完全无视了参数之间的结构关系。它不知道某 100 万个数字其实构成了一个“线性层矩阵”，它只把它们当成 100 万个互不相干的点。

2. Muon 的视角：尊重“结构”

Muon 的“聪明”之处在于它意识到：神经网络不是数字的堆砌，而是变换的组合。

  • 矩阵作为整体：Muon 认为，一个线性层的 $d \times d$ 矩阵不应该是 $d^2$ 个独立的维度，而是一个整体的变换算子。
  • 空间独立：Muon 确实为每个矩阵实施正交化。它在每个层的“局部空间”内，确保该层的变换方向（奇异向量）是均匀且正交的。

3. “整体”与“局部”的降维打击

我们可以用一个形象的比喻来总结 Adam 和 Muon 的空间观：

优化器 空间观 行为比喻
Adam 极其微观：每个参数都是一个独立的轴。 像是一个巨大的合唱团，指挥要求每个人根据自己的音量（梯度历史）独立调整声音大小，不管邻居唱什么。
Muon 结构宏观：每个层（矩阵）是一个独立的空间。 指挥将合唱团按声部（矩阵）分组。要求每个声部内部音域必须横跨高低音（正交化），且组与组之间独立推进。

4. 为什么 Muon 的“局部正交”比 Adam 的“全局自适应”快？

因为 Adam 在每个坐标轴上做的缩放，实际上可能破坏矩阵的性质。
例如，Adam 可能会放大梯度中原本就很小的噪声方向，缩小重要的主成分方向，因为它试图让每个轴的更新步长都变成一样的。

而 Muon 在局部矩阵空间里做 $U V^T$，它保证了：

  1. 不改变能量：正交变换不改变向量的范数，梯度的能量在通过层时不会被扭曲。
  2. 最大的探索率：因为它强迫每个奇异值都为 1，这相当于强迫模型在每一个可能的特征方向上都用相同的力度去“试探”，而不是只盯着那一两个已经很明显的特征（大奇异值方向）。

总结

  • Adam：是坐标轴级别的自适应（Coordinate-wise）。它把所有参数拉平，无视矩阵结构。
  • Muon：是算子级别的自适应（Operator-wise）。它承认矩阵的几何结构，并在每个矩阵内部寻求最优的正交骨架。
