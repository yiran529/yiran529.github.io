强化学习（RL）与监督微调（SFT）：定义、边界与统一视角

Posted on 2026-04-01 Edited on 2026-05-06 In LLM

一、什么是强化学习（Reinforcement Learning）

在主流教材（如 Sutton & Barto《Reinforcement Learning: An Introduction》）中，强化学习被定义为：

一个智能体（agent）通过与环境（environment）交互，根据奖励信号（reward）学习策略（policy），以最大化长期累计回报（return）的过程。

标准形式（MDP）

强化学习通常建模为一个马尔可夫决策过程（MDP）：

  • 状态：$ s \in \mathcal{S} $
  • 动作：$ a \in \mathcal{A} $
  • 转移：$ P(s’ \mid s, a) $
  • 奖励：$ r(s, a) $

策略 $ \pi(a \mid s) $ 的目标是最大化期望累计回报：

核心特征（学界共识）

强化学习与其他学习范式的关键区别在于：

  1. 只有奖励信号（evaluative feedback）

    • 不提供正确动作的标签
    • 只告诉“好或不好”

  2. 目标是长期回报（long-term return）

    • 需要跨时间做决策（temporal credit assignment）

  3. 数据来自交互（interaction-driven data）

    • 数据分布依赖当前策略（on-policy 或 off-policy）

二、什么是监督微调（SFT）

监督微调（Supervised Fine-Tuning）本质是标准监督学习：

特点：

  • 数据集 $D$ 是固定的
  • 每个输入都有明确标签 $y$
  • 目标是拟合数据分布

三、RL 与 SFT 的边界在哪里？

常见误解

很多人会说：

RL 有 reward，SFT 有 label

这个说法不够严格。

更本质的区分（推荐理解）

维度 SFT RL
数据来源 固定数据集 与环境交互产生
监督信号 明确标签（正确答案） 奖励（无正确答案）
目标函数 拟合数据分布 最大化长期回报
credit assignment 不涉及 核心问题
分布依赖 独立于模型 依赖当前策略

一句话总结

  • SFT：拟合已有正确答案
  • RL：在没有正确答案的情况下，通过试错学习最优行为

一个更严格的判定标准

如果一个方法满足：

  1. 数据依赖策略与环境交互
  2. 优化目标是 reward / return

那么它属于强化学习范式。

否则，如果：

  • 数据是静态的
  • 目标是拟合标签

那么它属于监督学习。

四、强化学习的常见分类

根据不同标准，RL 可以有多种划分方式。

1. 按是否依赖当前策略

On-policy

  • 使用当前策略采样数据并更新
  • 例：REINFORCE、PPO

Off-policy

  • 可以使用历史数据或其他策略的数据
  • 例：Q-learning、DQN

2. 按是否学习价值函数

Value-based

  • 学习 $ V(s) $ 或 $ Q(s,a) $
  • 策略通过 value 间接得到

代表：

  • Q-learning
  • DQN

Policy-based

  • 直接优化策略 $ \pi(a|s) $

代表：

  • REINFORCE

Actor-Critic

  • 同时学习：

    • actor：策略
    • critic：价值函数

代表：

  • A2C / A3C
  • PPO

3. 按优化方式

Policy Gradient

Q-learning / TD learning

Q-learning 是一种经典的 off-policy、value-based 强化学习算法，其核心思想是：

直接学习最优动作价值函数 $ Q^*(s,a) $，而不是显式学习策略。

Q-learning 的更新公式来源于 Bellman 最优方程（Bellman optimality equation）。它的关键特点是：

  • 使用当前观测到的奖励 $ r $
  • 加上下一状态的最大 Q 值 $ \max_{a’} Q(s’, a’) $ 作为 bootstrap 目标
  • 逐步逼近最优 Q 函数

这种方法属于 时序差分学习（Temporal-Difference Learning, TD），因为它用“当前估计 + 下一步估计”来更新，而不需要等到完整回合结束。

总结来说：

  • $ Q(s,a) $ 衡量“这个动作在这个状态下有多好”
  • Q-learning 通过不断迭代 Bellman 更新，学习一个最优的“动作评分函数”
  • 一旦 Q 学好，策略自然就是“选评分最高的动作”

五、PPO 与 DQN 的共同点（统一视角）

虽然 PPO 和 DQN 在形式上差异很大：

  • PPO：policy gradient + actor-critic
  • DQN：value-based + off-policy

但它们在本质上是统一的。

共同点 1：都在估计“动作有多好”

  • PPO：使用
  • DQN：使用

👉 都在回答：

在这个状态下，这个动作值不值得做？

共同点 2：都在做 policy improvement

可以用一个统一形式理解：

让好的 action 概率变高，让差的变低

具体实现：

  • PPO：

    • 正 advantage → 提高概率
    • 负 advantage → 降低概率

  • DQN：

    • 选择

共同点 3：都涉及探索与利用（exploration vs exploitation）

  • DQN：ε-greedy
  • PPO：随机采样 + entropy regularization

共同点 4：都依赖 bootstrapping（大多数情况）

  • DQN：TD target
  • PPO：通过 critic 估计 value

六、一个统一理解框架

可以用一个简单的统一视角理解三类方法：

SFT

👉 模仿“已知正确答案”

RL

👉 通过试错学习最优行为

Policy Improvement（统一本质）

所有 RL 方法本质都在做：

提高高价值动作的概率，降低低价值动作的概率

区别只在于：

  • 如何估计“价值”（Q / advantage / return）
  • 如何更新策略（argmax / gradient / clipping）

七、总结

  • 强化学习的本质：在没有标签的情况下，通过奖励信号学习最大化长期回报的策略
  • SFT 的本质：在有标签的情况下拟合数据分布
  • 两者的核心区别：是否依赖交互数据 & 是否优化 reward
  • PPO、DQN 等方法的共同点：都在通过不同方式实现 policy improvement

  • Silver, D. 强化学习课程（UCL）讲义
